ShowMark Android (v1.0) — APK বানানোর নিয়ম

পথ ১ (সবচেয়ে সহজ, Android Studio লাগবে না): GitHub দিয়ে
1) GitHub এ নতুন repo বানাও, এই ফোল্ডারের সব ফাইল (লুকানো .github সহ) আপলোড/push করো।
2) repo এর Actions ট্যাবে "Build APK" নিজে চলবে (বা Run workflow চাপো)। ২-৪ মিনিট লাগে।
3) শেষ হলে ওই রানের নিচে Artifacts > ShowMark-APK ডাউনলোড করে zip খুলে app-debug.apk ফোনে ইনস্টল করো
   (ফোনে "অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হবে)।

পথ ২: Android Studio — এই ফোল্ডারটা Open করো, Build > Build APK(s)।

ফোনে প্রথমবার:
1) ShowMark অ্যাপ খোলো > "অনুমতি দাও" > "অন্য অ্যাপের ওপর দেখানো" চালু করে ফিরে এসো।
2) "ShowMark চালু করো" > স্ক্রিন শেয়ারে "সম্পূর্ণ স্ক্রিন" (Entire screen) বেছে Start।
3) যেকোনো অ্যাপে গিয়ে ভাসমান ✨ চাপো > 🔍 জুম বা ✏️ আঁকা।

সেটিং (জুম বক্সের রঙ, রঙের পর্দা বাম/ডান, সাউন্ড মিউট, নিজের সাউন্ড যোগ) পিসির মতোই একই।
